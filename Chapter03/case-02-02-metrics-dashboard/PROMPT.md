# Case 02-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
你是数据分析专家。请读取两版产品迭代说明和历史数据，先做指标口径核对，再设计数据看板。
要求：
1. 输出指标体系：指标名称、业务定义、公式、数据源、更新频率、负责人、口径版本；
2. 两版文档有冲突时，以 v2 为候选新口径，但必须输出“口径冲突清单”供人工确认；
3. 看板包含附件全部核心指标，按获客、激活、活跃、留存、功能使用分版块；
4. 渠道、用户类型作为全域筛选；支持日/周/月趋势与自定义时间范围；
5. 活跃模块增加累计用户，条形图按人数倒序，榜单显示 TOP10；
6. 每张图可下载对应数据；生成断网可打开的单文件 HTML。
不要制造历史数据中不存在的正式结论；演示预测必须标注“模拟”。
```

## 追问提示语（演示校验与迭代）

```text
请把所有口径冲突按“影响高/中/低”排序，并说明若选错口径会影响哪些图表和决策。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
