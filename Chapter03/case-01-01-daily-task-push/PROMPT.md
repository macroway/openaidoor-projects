# Case 01-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
你是我的工作任务整理助手。请读取我上传的“本周任务口述稿”和“日历约束”，完成以下任务：
1. 按周一到周五整理本周任务，每项包含：任务、优先级、预计耗时、截止时间、依赖项、完成状态。
2. 把跨天任务拆成可执行的小步骤；发现时间冲突时明确标注。
3. 输出一个 Markdown 文件“本周任务清单.md”，后续每周都沿用这个固定文件名。
4. 再输出“今天的任务清单”，只保留今天应做的事项，按优先级排序，并给出总预计耗时。
5. 为每天工作日上午 8:45 的自动推送写出任务名称、执行时间、读取文件、推送内容模板。
不要虚构未提供的会议或截止时间；不确定项标记“待确认”。
```

## 追问提示语（演示校验与迭代）

```text
请检查今天的任务总耗时是否超过 7 小时。如果超过，请把可延期事项移到“候补任务”，并说明调整理由。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
