# Case 03-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
请对附件中的脱敏热门笔记样例做完整拆解，从标题策略、正文结构、视觉形式、标签矩阵、互动钩子五个维度分析，并总结：
1. 这篇笔记表现好的 3 个核心原因；
2. 哪些是事实证据，哪些只是合理推断；
3. 普通新手可复制的 3 个方法；
4. 套用到“AI 办公提效”赛道时如何替换变量；
5. 输出标题公式、正文模板、标签清单、变量替换表和发布前检查清单。
不要照抄原文，不要承诺“必爆”；评论区仅用于分析互动需求。
```

## 追问提示语（演示校验与迭代）

```text
请再生成 3 个不同强度的标题版本：克制型、反差型、强钩子型，并逐个说明潜在风险。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
