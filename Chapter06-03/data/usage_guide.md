# 家居产品使用说明摘要

## A102 云朵椅

- 适合客厅、阅读角等静态坐姿场景。
- 请勿站立、跳跃或在椅面上放置超过 120 千克的物品。
- 新购产品如有轻微布艺气味，通风 24～48 小时后再使用。

## B205 实木椅

- 四脚需放置于平整地面，避免单脚悬空造成结构应力。
- 黑色款与原木色款尺寸一致，仅表面处理不同。

## C301 透明收纳箱

- 叠放时不超过 3 层，且最下层需放置于干燥平面。
- 不可用于存放液体、尖锐物或未密封的化学品。

## D118 折叠床

- 每次展开后必须确认四脚锁扣全部扣紧。
- 单人使用，不建议两名成年人同时使用。
