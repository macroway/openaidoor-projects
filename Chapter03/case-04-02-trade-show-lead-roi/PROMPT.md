# Case 04-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
你是一名新能源汽车行业 B 端市场运营和销售分析人员。请读取展会复盘原始资料和会议纪要：
1. 统一企业名称和字段格式；疑似重复只标记不删除，保留原始记录和来源；
2. 按主机厂、零部件、经销商、供应链、技术合作方、媒体及其他分类；
3. 按目标客户、应用场景、采购/测试/报价计划、项目时间、决策人、下一步约定，将商机评为 A/B/C/D，每项列依据，信息不足标“待确认”；
4. 将展位、搭建、运输、差旅、活动、接待、传播、物料、人员时间和展后跟进纳入真实成本，计算单个登记客户、目标客户、有效商机和 A 级商机成本；
5. 生成面向管理层、销售和市场的不同交付物，并给出下一届维持/缩减/退出建议。
严格区分事实、判断、待确认；公开报告中不出现私人联系方式。
```

## 追问提示语（演示校验与迭代）

```text
请输出“最可能被错误合并的重复记录”清单，以及每对记录应合并/不合并/待确认的理由。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
