# 预期输出结构｜批量分析客服工单反馈

本文件用于课堂验收，不提供唯一标准答案。AI 生成结果可不同，但必须覆盖以下交付物：

1. **客户投诉月度分析报告.md**：包含清晰标题、生成日期、数据范围、来源/输入说明和限制。
2. **工单归类明细.csv**：包含清晰标题、生成日期、数据范围、来源/输入说明和限制。
3. **投诉类型分布图**：包含清晰标题、生成日期、数据范围、来源/输入说明和限制。

## 最低质量线

- 内容正确优先于视觉效果。
- 所有汇总数字能与明细对上。
- 所有判断都有规则或证据。
- 对模拟、脱敏、推断和实时待核验信息做显眼标注。
- 输出可由另一位学员在不阅读对话历史的情况下理解和复核。
