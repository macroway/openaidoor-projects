# Case 08-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
请基于附件演示数据制作“青岛三日游”单文件 HTML 页面。出发地上海虹桥，行程为 8 月 14–16 日，偏好人文建筑、少走回头路、不安排纯网红打卡。
页面包含：三日速览、交通双方案、精确到小时的时间轴、住宿区域建议、本地美食与觅食街区、8 月专项贴士、出发前复核清单。
要求：
1. 移动端优先，顶部导航和时间轴清晰；
2. 所有 CSS/JS 内嵌，断网可打开；
3. 附件中的价格、开放时间均为课堂模拟，不得描述为最新事实；
4. 对门票、开放时间、天气、交通班次等易变化信息加“出发前联网复核”标签；
5. 图片区域使用有版权说明的占位卡，不伪造 Wikimedia 来源。
```

## 追问提示语（演示校验与迭代）

```text
请检查三天路线是否存在明显折返，并把每个需实时确认的信息汇总到“出发前 48 小时复核”清单。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
