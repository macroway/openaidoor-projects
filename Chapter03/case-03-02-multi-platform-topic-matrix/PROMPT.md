# Case 03-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
你是有五年以上经验的多平台内容运营总监。请读取“趋势弹药库”“对标内容样例”和“品牌事实库”，围绕【办公工具替内容运营打工】产出一份单文件 HTML 选题矩阵报告。
报告需包含：
1. 标题与 80 字导语；
2. 小红书、公众号、抖音三列平台风向卡；
3. 至少 15 行主题×平台矩阵：编号、主题角度、三平台标题/钩子、共同情绪钩子、证据来源、预期互动等级；
4. 72 小时错峰发布排期；
5. 复用提示词模板；
6. 参考资料清单。
风格：暗色科技风，背景 #0E1116，强调色 #00E5FF，断网可打开。所有数据性说法只能来自附件；预测项明确标“预估”。
```

## 追问提示语（演示校验与迭代）

```text
从矩阵中选第 3 个主题，分别生成小红书 500–800 字图文、公众号 1500 字提纲、抖音 60 秒口播稿。三种调性不得串台。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
