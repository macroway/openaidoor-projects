# Case 07-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
你是学习笔记整理助手。读取原始文章并按规则输出：
1. 标题与来源信息：作者、发布日期、原文标识、整理日期；
2. 【核心结论】2–4 句，结论先行；
3. 分点展开：对比信息用表格、流程用列表、观点用短段落；
4. 不逐字摘抄，保留关键定义与限定条件；
5. 判断归档类别并更新知识库目录，不能产生重复记录；
6. 提炼知识卡片文案：标题≤10字、三栏各≤15字、金句≤20字、总字数≤70字；
7. 输出验证报告：来源、链接标识、分类、去重、卡片字数、文件名。
本次为离线课堂，不调用外部文档 API；把在线归档步骤写成待执行清单。
```

## 追问提示语（演示校验与迭代）

```text
请比较“结构化学习笔记”和原文，列出被省略但可能影响理解的 3 个限定条件，并决定是否补回。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
