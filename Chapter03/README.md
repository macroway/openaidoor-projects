# Chapter04｜第三章 AI 办公提效教学素材库

本目录把《第三章 AI办公提效：各行各业的X种用法》中的 15 个案例整理为可直接授课、演示和练习的案例包。

## 快速使用

1. 先看 `TEACHER_INDEX.md` 选择案例。
2. 进入对应 case，按 README 的“开箱演示”执行。
3. 先上传 `inputs/`，再复制 `PROMPT.md`。
4. 用验收清单抽查，不把 AI 首次输出当成最终答案。

## 统一结构

每个案例都有 README、提示语、输入素材、讲师脚本、学员练习页、验收清单和预期输出结构。涉及表格的案例同时提供 Excel 或 CSV；需要联网/账号的案例提供离线备援素材。

## 数据与版权

- 全部姓名、公司、联系方式、候选人、客户与业务指标均为虚构或脱敏。
- 旅游开放时间、价格、交通等为课堂模拟，不代表 2026 年真实情况。
- 社交平台内容为原创教学样例，不复制真实帖子。
- 不包含真实招聘平台简历、真实客户记录或受限内部材料。

## 案例总数

共 15 个 case。可在 `case_manifest.csv` 中筛选主题、时长、输入和交付物。
