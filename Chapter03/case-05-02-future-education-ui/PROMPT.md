# Case 05-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
第一阶段只做规划，不出图：我要设计一套“未来教育系统”。请结合附件用户画像，规划学生、老师、家长、管理者各自的核心任务、痛点和功能；给出信息架构、模块、页面清单、优先级和关键用户流程。不要默认所有功能都需要 AI。

我确认后进入第二阶段：按确认的清单输出 6 张核心页面的详细设计。风格为科技感、深色底、蓝紫渐变点缀；同时满足可读性、键盘可操作、对比度和移动端适配。页面必须使用附件中的示例内容，避免空洞占位符。
```

## 追问提示语（演示校验与迭代）

```text
请先只做学生端“今日学习台”一个页面，提供两个明显不同的布局方向，并解释各自更适合什么使用情境。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
