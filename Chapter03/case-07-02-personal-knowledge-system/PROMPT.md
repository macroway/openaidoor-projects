# Case 07-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
请围绕附件中的研究问题，整理我有权使用的内部演示材料：
1. 核心结论：只写有来源支持的内容；
2. 关键信息：按概念、现状、常见做法和待验证问题归类；
3. 来源清单：每条结论对应材料名、日期和段落标识；
4. 待确认项：标出信息不足、已过期或不同说法；
5. 知识笔记：沉淀关键词、关联概念、适用边界和下一步阅读方向。
规则：新版材料不一定自动正确，但版本冲突必须显式呈现；不要把观点写成事实，不要编造外部依据。
```

## 追问提示语（演示校验与迭代）

```text
请把所有跨版本冲突做成表格：主题、旧版说法、新版说法、支持来源、当前建议、仍需向谁确认。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
