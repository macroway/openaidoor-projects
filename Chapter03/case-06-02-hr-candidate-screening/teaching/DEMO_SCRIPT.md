# 讲师演示脚本｜HR 快速筛选简历

## 课前准备（2 分钟）

1. 展示本案例 README 的学习目标。
2. 打开 inputs，说明数据是虚构/脱敏或离线模拟。
3. 让学员先预测 AI 最容易犯的一个错误。

## 演示流程

### 1. 只看素材，不急着下指令（2 分钟）

请 AI 列出文件、字段、时间范围、缺失值和潜在冲突。讲解：高质量办公任务先做“输入审计”。

### 2. 运行主提示语（5–12 分钟）

复制 PROMPT.md 的主提示语。执行过程中重点观察：是否完整读取附件、是否明确口径、是否保留来源标识、是否把推断冒充事实。

### 3. 人工验收（3–5 分钟）

使用 ACCEPTANCE_CHECKLIST.md。不要只看页面漂亮与否，要抽查原始记录、合计数、日期、公式和判断依据。

### 4. 运行追问（2–5 分钟）

复制追问提示语，展示 AI 如何进行自检、修复和版本迭代。

## 讲解重点

- AI 的价值不只是“生成”，还包括读取、归类、转换、核对和沉淀流程。
- 提示语应同时写清：输入、目标、规则、交付格式、验收标准和禁止事项。
- 对关键数字、个人信息、招聘判断和实时信息保留人工复核。

## 离线备援

如果联网、登录、外部 API 或网页访问不可用，完全使用 inputs 中的离线素材；要求 AI 把“本应联网完成”的步骤写为待执行清单。离线备援不影响本案例的核心教学目标。

## 课堂提问

1. 哪一条要求最能减少幻觉？
2. 哪个输出字段最方便人工复核？
3. 如果换成你的业务，哪些变量要替换？
