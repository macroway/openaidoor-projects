# Case 02-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
以下附件是我司本月客户投诉工单，请完成：
1. 先阅读全部工单，归纳 5–8 个互斥且尽量穷尽的投诉类型，并给出定义和边界；
2. 将每条工单归到一个主类型，可附一个次标签；
3. 统计每类数量和占比，用饼图展示，并确保数量合计等于原始工单数；
4. 列出 TOP 10 高频具体问题；
5. 针对占比最高的两类，各给出 3 条可落地改进建议，明确负责人建议和衡量指标；
6. 输出中文完整报告和带原工单编号的归类明细。
注意：不要把客户姓名、电话等个人信息写进公开报告。
```

## 追问提示语（演示校验与迭代）

```text
请做一次质量复核：列出最难判断的 5 条工单、当前分类、备选分类和判断依据，并检查各类数量之和是否为 80。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
