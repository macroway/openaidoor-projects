# Case 02-01｜批量分析客服工单反馈

> 第三章「数据分析与可视化」课堂演示包  
> 建议时长：18–22 分钟｜所有案例数据均为虚构、脱敏或离线模拟，仅供教学。

## 学习目标

从 80 条工单归纳分类、逐条打标、统计占比并形成改进建议。

## 开箱演示

1. 打开 `inputs/`，按顺序上传或粘贴全部素材。
2. 复制 `PROMPT.md` 中的“主提示语”运行。
3. 参照 `teaching/DEMO_SCRIPT.md` 在关键节点暂停讲解。
4. 用 `teaching/ACCEPTANCE_CHECKLIST.md` 验收结果。
5. 若时间允许，再运行“追问提示语”，演示校验与迭代。

## 输入素材

- `inputs/客户投诉工单_80条.csv`
- `inputs/字段说明.md`

## 预期交付物

- 客户投诉月度分析报告.md
- 工单归类明细.csv
- 投诉类型分布图

## 文件夹说明

- `inputs/`：可直接上传的演示数据。
- `PROMPT.md`：可复制的主提示语、追问和变量说明。
- `teaching/DEMO_SCRIPT.md`：讲师口播、操作节点和离线备援。
- `teaching/STUDENT_WORKSHEET.md`：学员记录和练习页。
- `teaching/ACCEPTANCE_CHECKLIST.md`：交付物验收标准。
- `expected/OUTPUT_SPEC.md`：预期结果结构，不是固定答案。

## 安全说明

素材中的人名、公司、账号、联系方式、业务指标均为虚构；不要据此作真实招聘、商业、出行或个人决策。真实场景中需重新核验权限、隐私、时效性和来源。
