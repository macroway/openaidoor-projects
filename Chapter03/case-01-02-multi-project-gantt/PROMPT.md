# Case 01-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
帮我把附件中的 12 个项目进度数据合并成一张甘特图看板，生成可直接在浏览器打开的单文件 HTML 页面。
要求：
1. 按时间轴横向展示每个项目的各阶段进度条；
2. 状态颜色严格使用：绿色=正常推进，黄色=有延期风险，红色=已延期，灰色=未开始；
3. 顶部显示项目总数、正常数、风险数、延期数和未来 14 天关键节点数；
4. 支持按负责人和状态筛选；每个项目可点击查看阶段、计划日期、负责人、风险说明；
5. 另输出一份风险项目清单，列出风险依据和建议动作；
6. 所有 CSS 与 JavaScript 内嵌，不引用外部资源。
先检查 12 份表的字段和日期口径；发现冲突或缺失时先列出，不要自行猜测。
```

## 追问提示语（演示校验与迭代）

```text
把“星云支付升级”项目状态改为绿色，并在详情中记录“接口联调已提前完成”；同时重新计算顶部状态统计。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
