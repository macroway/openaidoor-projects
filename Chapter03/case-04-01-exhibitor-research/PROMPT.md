# Case 04-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
这是一个课堂离线模拟展会站点。请先读取 mock_exhibitors_page.html，识别它引用的数据文件 mock_exhibitors_api.json，然后批量整理全部展商。
字段：公司名称、行业、主营业务、展馆位置、合作伙伴类型。
按附件评分规则计算 0–100 分，并输出每家公司各维度得分、总分、相关等级和理由。交付：
1. Excel：概览、全部展商、高相关展商、评分规则 4 个工作表，按总分降序；
2. 单文件 HTML 报告：KPI 卡片、行业分布、等级分布、展馆分布、TOP20；
3. 抓取与评分说明：明确数据来源、规则和限制。
不要把模拟数据描述成真实展会数据；所有推断必须可回溯到字段或规则。
```

## 追问提示语（演示校验与迭代）

```text
随机抽查 5 家展商，逐项展示评分计算过程，并检查总分是否等于四个维度之和。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
