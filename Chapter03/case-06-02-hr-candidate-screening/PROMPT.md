# Case 06-02 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
请在附件 30 位虚构候选人中筛选不超过 10 位物业工程主管候选人。
硬性条件：电工证+制冷证、中央空调维保经验、年龄 45 以下、期望薪资 9K–10K 可协商。
排序逻辑：硬性条件通过 > 证书完整度 > 相关经验 > 项目复杂度；学历、性别等与岗位胜任无直接关系的字段不得作为加减分依据。
每位输出：编号、年龄、工作年限、当前职位、证书证据、维保经验、薪资判断、匹配分、核心亮点、风险/待核实项。另输出所有被淘汰者的淘汰原因代码。
这是教学模拟数据，不得把结果用于真实招聘决策；最终必须由 HR 人工复核。
```

## 追问提示语（演示校验与迭代）

```text
请做公平性复核：检查排序是否误用了性别、学校或其他无关属性，并把所有“待核实”候选人列成电话核验问题清单。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
