# Case 06-01 提示语

## 使用前

- 将 `inputs/` 中列出的文件全部上传。
- 告诉 AI：“这些是课堂虚构/脱敏素材，只按附件处理。”
- 如工具无法读取某种格式，可使用同目录的 CSV、TXT 或 Markdown 备份。

## 主提示语

```text
请读取 5 份研学教师 JD，提取共性的能力关键词 TOP10 并按出现频率排序。然后对照脱敏简历和“可核实经历补充表”：
1. 计算岗位匹配点、缺口和证据强度；
2. 逐条给出修改前、修改后、修改原因；
3. 生成完整优化版简历，每段经历尽量包含可核实的量化结果；
4. 生成三类投递话术和 7 天跟进节奏。
不得编造证书、经历、数字或机构名称；缺少数据时写“建议本人补充确认”，不要替候选人补造。
```

## 追问提示语（演示校验与迭代）

```text
请逐句审计优化版简历，把每个数字和能力主张映射到附件证据；没有证据的句子标红并给出降级表达。
```

## 通用纠偏提示语

```text
请暂停生成新内容，先做质量审计：
1. 列出你使用的每个输入文件；
2. 标出所有事实、推断和待确认项；
3. 检查总数、比例、日期、字段映射和去重是否自洽；
4. 只修复能由附件证实的问题，不要补造数据；
5. 输出修订清单后再更新交付物。
```
